# 🐍💧🔫 Snake Water Gun Game (Python)

A classic command-line implementation of the popular **Snake, Water, Gun** game built using Python. Play against the computer and test your luck!

## 🚀 Game Rules
* **Snake** drinks Water (Snake wins).
* **Water** dunks Gun (Water wins).
* **Gun** shoots Snake (Gun wins).
* Same choice results in a Draw.

## 🚀 Features
* Random computer choice generation using Python's `random` module.
* Interactive terminal input loop to play multiple rounds.
* Instant win/loss/draw results.

## 📂 Project Structure
* `main.py` - Main Python script containing the game logic and score checks
* `README.md` - Project documentation
