# 💰 Simple Expense Tracker (Python)

A console/command-line based Python application to track, manage, and view your daily expenses easily.

## 🚀 Features
* Add new expenses with categories and amounts.
* View total spending and history.
* Lightweight and built purely with Python.

## 📂 Project Structure
* `main.py` - Main Python script to run the application
* `README.md` - Project documentation
